# Challenge 6 - React + TypeScript

Aplicacion construida solo con React + TypeScript que incluye:

- Login, Register y Logout con Firebase Auth.
- Routing con paginas protegidas.
- Un contexto para autenticacion.
- Un contexto para tareas compartidas entre paginas.
- App de tareas con crear, editar, eliminar y toggle done.
- Estilos con Bootstrap (libreria CSS) + SASS.

## Configuracion

1. Copia `.env.example` a `.env`.
2. Completa las variables con tu proyecto de Firebase.
3. Instala dependencias y ejecuta el proyecto.

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```
